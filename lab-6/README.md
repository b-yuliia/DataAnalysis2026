# Лабораторна робота №6: C++ openCV

Програма захоплює відеопотік з камери в реальному часі, обробляє його за допомогою різних фільтрів та відображає результат у вікні. Головною особливістю є модульна структура: кожен етап (захоплення, обробка, логіка клавіш, відображення) винесений в окремий клас.

## Мета роботи
Набуття практичних навичок роботи з бібліотекою комп'ютерного зору OpenCV, розробка програм із модульною архітектурою на C++, автоматизація збірки проєкту за допомогою CMake та написання скриптів автоматизації для Linux систем.

## Технології
- **Мова:**
    - C++
- **Бібліотека:**
    - OpenCV 4.x
- **Система збірки:**
    - CMake & Make
- **Операційна сисема:**
    - Linux (тестовано на Ubuntu у VMware)
## Вимоги до системи

Для коректної роботи програми ваша система повинна відповідати наступним характеристикам:

#### Програмні вимоги:
*   **Операційна система:** ОС Ubuntu 20.04 LTS або новіша.

## Інструкція користувача
1. **Швидкий старт (для перевірки):** Для збірки та запуску програми на "чистій" системі виконайте наступні команди в терміналі:
```
git clone -b lab-6 https://github.com/b-yuliia/DataAnalysis2026.git
```
```
cd lab-6
```
```
chmod +x preinstall.sh build.sh run.sh
```
```
./preinstall.sh
```
```
./build.sh
```
```
./run.sh
```
2. **Керування програмою:**
Після запуску відкриється вікно відеопотоку. Переконайтеся, що вікно знаходиться у фокусі (активне) та встановлена англійська розкладка клавіатури.

**Зміна режимів (клавіші 0-5):**

* **0: Normal** — вихідне зображення без фільтрів.

* **1: Inversion** — інверсія всіх кольорів кадру.

* **2: Grayscale** — перетворення зображення у відтінки сірого.

* **3: Canny Edges** — виділення контурів об'єктів.

* **4: Gaussian Blur** — розмиття зображення.

* **5: Glitch Effect** — художнє зміщення колірних каналів (R-shift).

**Інтерактивні елементи:**
* **Слайдер "Brightness":** Дозволяє в реальному часі змінювати яскравість відеопотоку.

* **ESC:** Вихід з програми та закриття всіх вікон.

## Структура проєкту
* src/ — файли реалізації (.cpp)

* include/ — заголовні файли (.hpp)

* preinstall.sh — встановлення залежностей.

* build.sh — компіляція проєкту через CMake.

* run.sh — запуск готового бінарного файлу.

* CMakeLists.txt — конфігурація збірки.
