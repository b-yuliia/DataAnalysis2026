# Лабораторна робота №2. Наука про дані: підготовчий етап
## Опис завдання
#### Ця лабораторна робота присвячена обробці та аналізу великого набору даних (понад 2 мільйони записів) про енергоспоживання домогосподарств за допомогою бібліотеки Pandas. У роботі реалізовано повний цикл підготовки даних: від очищення та фільтрації до статистичного аналізу та масштабування.
### Метою роботи є опанування методів ефективної обробки великих датасетів (Big Data) мовою Python. Основні етапи аналізу:
* Data Cleaning: завантаження, видалення пропусків та типізація даних.
* Складна фільтрація: вибірка даних за логічними умовами та часовими проміжками (пікові навантаження).
* Випадкове семплювання: робота з репрезентативними вибірками обсягом 500,000 записів.
* Статистичний аналіз: розрахунок кореляцій Пірсона та Спірмена для фізичних показників.
* Трансформація даних: масштабування (Min-Max), стандартизація (Z-score) та One Hot Encoding часових категорій.
## Підготовчий етап
### Вимоги до системи
* Операційна система: Windows / macOS / Linux
* Python: версія 3.10 або новіша (рекомендовано 3.14).
* Оперативна пам'ять: мінімум 4 ГБ (через завантаження всього датасету в RAM).
* Проект містить файл requirements.txt для швидкого розгортання середовища.
## Інструкція з запуску
1. Клонуйте репозиторій:
git clone https://github.com/ваш-логін/назва-репозиторію.git
cd назва-репозиторію
2. Створіть та активуйте віртуальне середовище:
```
python -m venv venv
```
*Для Windows:*
``` 
venv\Scripts\activate
```

*Для Linux/MacOS:*
```
source venv/bin/activate
```
3. Встановіть залежності з файлу:
```
pip install -r requirements.txt
```
4. Завантажте файл household_power_consumption.txt із сайту https://archive.ics.uci.edu/dataset/235/individual%2Bhousehold%2Belectric%2Bpower%2Bconsumption та розташувати у теці Lab-2.
5. Запустити Jupyter Notebook в терміналі: 
```
jupyter notebook
```
6. Запустіть аналіз:

Відкрийте Lab2part2.ipynb файл і виконайте всі комірки по черзі.
