# Лабораторна робота: Візуалізація даних 2

Ця лабораторна робота присвячена вивченню гармонійних коливань, впливу випадкового шуму на сигнали та методів цифрової фільтрації. Програма реалізована на мові Python з використанням бібліотеки Matplotlib для створення інтерактивного інтерфейсу.

## Мета роботи
- Дослідити поведінку гармонійної функції $y(t) = A \cdot \sin(\omega t + \phi)$.
- Навчитися моделювати випадкові завади (білий шум) з різними статистичними параметрами.
- Реалізувати алгоритм фільтрації сигналу (Savitzky-Golay filter) та оцінити його ефективність шляхом порівняння з еталонним сигналом.
- Отримати навички побудови інтерактивних GUI-елементів для маніпуляції даними в реальному часі.

## Технології
- **Python 3.x**
- **NumPy** — робота з масивами та генерація сигналів.
- **Matplotlib** — візуалізація та створення віджетів (слайдери, кнопки, чекбокси).
- **SciPy** — цифрова обробка сигналів та фільтрація.

## Опис функціоналу
Програма відображає графік, на якому одночасно представлені:
1. **Еталонна гармоніка** (синя пунктирна лінія) — ідеальний математичний сигнал.
2. **Зашумлений сигнал** (помаранчева лінія) — результат накладання нормального розподіленого шуму на гармоніку.
3. **Відфільтрований сигнал** (фіолетова лінія) — результат обробки зашумлених даних фільтром Савицького-Голея.

### Основні параметри керування:
- **Гармоніка:** Амплітуда (A), Частота (f), Фазовий зсув (φ).
- **Шум:** Середнє значення (M), Дисперсія (D).
- **Фільтр:** Розмір вікна згладжування (Window size).
