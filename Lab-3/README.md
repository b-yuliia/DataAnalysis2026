# Лабораторна робота №3. Візуалізація даних
## Опис завдання
#### Ця лабораторна робота очищенню, обробці та візуалізації набору даних про характеристики автомобілів.
### Мета роботи — виявити закономірності між технічними параметрами (потужність, об'єм двигуна, вага) та вартістю авто. Основні етапи аналізу:
* Завантаження та первинний аналіз.
* Очищення даних (Data Cleaning). Виявлення пропущених значень, заповнення числових пропусків середнім значенням, обробка категоріальних даних (заміна на моду), видалення рядків із відсутньою цільовою ознакою (price).
* Візуалізація та аналіз.
## Підготовчий етап
### Вимоги до системи
* Операційна система: Windows / macOS / Linux
* Python: версія 3.10 або новіша (рекомендовано 3.14).
* Оперативна пам'ять: мінімум 4 ГБ (через завантаження всього датасету в RAM).
* Проект містить файл requirements.txt для швидкого розгортання середовища.
## Інструкція з запуску
1. Створіть та активуйте віртуальне середовище:
```
python -m venv venv
```
*Для Windows:*
``` 
venv\Scripts\activate
```

*Для Linux/MacOS:*
```
source venv/bin/activate
```
2. Встановіть залежності з файлу:
```
pip install -r requirements.txt
```
3. Завантажте архів automobile.zip із сайту https://archive.ics.uci.edu/dataset/10/automobile та розташувати у теці Lab-3.
4. Запустити Jupyter Notebook в терміналі: 
```
jupyter notebook
```
5. Запустіть аналіз:

Відкрийте Lab-3.ipynb файл і виконайте всі комірки по черзі.
