# Лабораторна робота №5: Наука про дані: обмін результатами та початковий аналіз

Ця лабораторна робота є веб-додатком для інтерактивного аналізу та візуалізації екологічних показників (VCI, TCI, VHI) для різних областей України. Програма дозволяє фільтрувати дані за часовими інтервалами, порівнювати регіони та проводити базовий статистичний аналіз через зручний вебінтерфейс.

## Мета роботи
Метою роботи є створення інтерактивного інструменту для обміну результатами дослідження даних. Додаток реалізує:
- Завантаження та очищення даних з декількох CSV-файлів.
- Фільтрацію за показниками, регіонами, роками та тижнями.
- Візуалізацію часових рядів та порівняльний аналіз між областями.
- Динамічне сортування та скидання налаштувань.

## Технології
- **Інтерактивні фільтри (Бічна панель):**
    - Вибір часового ряду: **VCI**, **TCI** або **VHI**.
    - Вибір області зі списку (автоматично формується з наявних файлів).
    - Слайдери для вибору діапазону **тижнів** (1–52) та **років**.
    - Кнопка **"Скинути всі фільтри"** для миттєвого повернення до початкового стану.
- **Сортування даних:**
    - Можливість сортування таблиці за зростанням або спаданням обраного показника за допомогою чекбоксів.
- **Візуалізація (Вкладки):**
    - `Таблиця`: Відображення відфільтрованих сирих даних.
    - `Графік області`: Лінійний графік динаміки обраного показника для конкретного регіону.
    - `Порівняння`: Стовпчикова діаграма середніх значень показника між усіма наявними областями за обраний період.

## Вимоги до системи

Для коректної роботи програми ваша система повинна відповідати наступним характеристикам:

*   **Операційна система:** Windows / macOS / Linux.
*   **Python:** версія 3.10 або новіша (рекомендовано 3.14).
*   **Оперативна пам'ять:** мінімум 4 ГБ (через специфіку обробки сигналів та завантаження даних у RAM).
*   **Залежності:** Проєкт містить файл `requirements.txt` для швидкого розгортання середовища та встановлення всіх необхідних бібліотек.


## Інструкція користувача
1. Переконайтеся, що файл зі скриптом (`Lab-5.py`) та папка з даними (`vhi_data/`) знаходяться в одній директорії.

2. **Налаштування віртуального середовища:**
```
   # Створення
   python -m venv venv
   
   # Активація (Windows)
   venv\Scripts\activate
```
3. **Встановлення залежностей:**
```
pip install -r requirements.txt
```
4. **Запуск додатка:**
```
streamlit run Lab-5.py
```
